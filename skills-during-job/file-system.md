### **File Extensions & File Properties Test – Task Guidelines & Assessment Questions**  

This test will gauge students' understanding of **file extensions, file types, sizes, properties, and folder management** in Windows.  

---

### **Task Guidelines (Skills to be Tested)**  

#### **1. Understanding File Extensions & Their Uses**  
✅ Explain the purpose of file extensions and why they are necessary.  
✅ List the key differences between the following file formats:  
   - **.JPG vs .PNG** (image formats)  
   - **.TXT vs .DOCX** (text-based formats)  
   - **.PDF vs .DOCX** (document formats)  

#### **2. File Properties & Metadata**  
✅ Find and list the following properties for any file:  
   - **File Type**  
   - **File Size**  
   - **Date Created**  
   - **Date Modified**  
   - **File Location**  
✅ Change the modified date of a file by opening and saving it again.  

#### **3. File Size Comparison**  
✅ Save the same text content in both **.TXT** and **.DOCX** formats.  
✅ Compare their file sizes and explain why they differ.  
✅ Save the same image in both **.JPG** and **.PNG** formats.  
✅ Compare their file sizes and discuss the differences.  

#### **4. Folder Size Calculation**  
✅ Create a folder named **"Test Folder"**.  
✅ Place at least **five different files** inside it.  
✅ Check the **total folder size** by right-clicking → **Properties**.  

#### **5. Changing File Extensions & Their Effects**  
✅ Enable **file extensions** in Windows Explorer.  
✅ Rename a **.TXT** file to **.DOCX** and try opening it.  
✅ Rename a **.JPG** file to **.PNG** and check what happens.  

#### **6. Creating Shortcuts & Accessing Files Efficiently**  
✅ Create a **desktop shortcut** for a frequently used file.  
✅ Pin a frequently used file (e.g., a .DOCX report) to **Quick Access**.  
✅ Pin an application like **Notepad** or **Word** to the Taskbar.  

---

### **Assessment Questions (Based on the Guidelines)**  

1. **What is the purpose of file extensions in Windows?**  
2. **What is the difference between .JPG and .PNG file formats?**  
3. **Why is a .TXT file usually smaller in size than a .DOCX file?**  
4. **What is the main difference between .PDF and .DOCX formats?**  
5. **How can you check the size of a file or folder in Windows?**  
6. **What happens if you rename a .TXT file to .DOCX? Will it function properly?**  
7. **Why is a .JPG file usually smaller than a .PNG file?**  
8. **How do you enable file extensions in Windows Explorer?**  
9. **What is the purpose of the "Date Modified" property of a file?**  
10. **If a folder contains 10 files, each 5MB in size, what will be the approximate folder size?**  
11. **How do you create a shortcut for a file on the desktop?**  
12. **How do you pin a file to Quick Access for faster access?**  
13. **Which file format would you use if you want to preserve formatting but prevent edits: .PDF or .DOCX?**  
14. **What is the purpose of metadata in file properties?**  
15. **How do you change a file’s extension in Windows?**
