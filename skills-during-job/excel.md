### **Excel Task Guidelines (Skills to be Tested)**  

#### **1. Workbook & Worksheet Formatting**  
✅ Rename the worksheet to **"Sales Report"**.  
✅ Apply a **header row** with bold formatting.  
✅ Adjust **column widths** to fit content properly.  
✅ Use **cell borders** to improve table readability.  
✅ Apply a **cell background color** to header cells.  

#### **2. Data Entry & Formatting**  
✅ Enter **sample sales data** with the following columns:  
   - **Date** (Formatted as "MM/DD/YYYY")  
   - **Product Name**  
   - **Quantity Sold**  
   - **Unit Price**  
   - **Total Sales** (Quantity Sold × Unit Price)  
✅ Format **currency values** to display as **$XX.XX**.  
✅ Use **AutoFill** to extend formulas where applicable.  

#### **3. Formulas & Functions**  
✅ Use the **SUM** function to calculate total sales for all products.  
✅ Use the **AVERAGE** function to find the average sales per product.  
✅ Use the **IF function** to label sales above $500 as **"High"**, otherwise **"Low"**.  
✅ Use the **VLOOKUP or XLOOKUP** function to find a product's price based on its name.  

#### **4. Charts & Graphs**  
✅ Insert a **bar chart** or **column chart** showing total sales per product.  
✅ Label the chart with a **title, axis labels, and legend**.  
✅ Modify chart colors for clarity.  

#### **5. Sorting & Filtering**  
✅ Sort the data in **descending order** based on total sales.  
✅ Apply a **filter** to display only products with sales greater than $300.  

#### **6. Conditional Formatting**  
✅ Use conditional formatting to highlight sales **above $500 in green** and **below $200 in red**.  

#### **7. Data Validation**  
✅ Apply **data validation** to the "Quantity Sold" column, allowing only whole numbers greater than 0.  

#### **8. Pivot Tables**  
✅ Create a **Pivot Table** summarizing total sales per product.  
✅ Use the Pivot Table to display total sales for each month.  

#### **9. Protecting & Reviewing the Worksheet**  
✅ Lock the "Unit Price" column to **prevent editing**.  
✅ Use the **Spell Check** tool to review data entry.  

#### **10. Saving & Exporting**  
✅ Save the file as **Excel Workbook (.xlsx)**.  
✅ Export the report as a **PDF**.

### **Assessment Questions (Based on the Guidelines)**  
1. **How do you apply bold formatting to the header row in Excel?**  
2. **What is the purpose of the AutoFill feature in Excel?**  
3. **Write the formula to calculate total sales if Quantity is in column C and Unit Price is in column D.**  
4. **Which function would you use to find the highest sales value in a range?**  
5. **How do you insert a bar chart in Excel?**  
6. **What steps are required to filter data to show only products with sales above $300?**  
7. **How do you apply conditional formatting to highlight values greater than $500 in green?**  
8. **What is the difference between VLOOKUP and XLOOKUP?**  
9. **How do you create and modify a Pivot Table?**  
10. **How do you protect specific cells in an Excel worksheet from being edited?**
