### **Microsoft Word Skills Test – Report Writing Guidelines**  

Write a report. 

---

### **Report Writing Guidelines (Skills to be Tested)**  

#### **1. Document Formatting**  
✅ Set page size to **A4** with **1-inch margins** on all sides.  
✅ Set line spacing to **1.5** throughout the document.  
✅ Use **Calibri (12pt)** or **Times New Roman (12pt)** for body text.  
✅ Ensure **justified alignment** for paragraphs.  

#### **2. Cover Page**  
✅ Create a cover page with:  
   - **Title of the Report** (Centered, Bold, 20pt)  
   - **Your Name** (Centered, 14pt)  
   - **Institution Name** (Centered, 14pt)  
   - **Date** (Centered, 12pt)  

#### **3. Headings and Styles**  
✅ Apply **Heading 1** style for main headings.  
✅ Apply **Heading 2** style for subheadings.  
✅ Use the **Navigation Pane** to check document structure.  

#### **4. Page Numbering & Sections**  
✅ Insert **automatic page numbers** at the **bottom right** of each page.  
✅ Ensure the **cover page does NOT have a page number**.  
✅ Use **section breaks** to separate different sections (e.g., Cover Page vs. Main Content).  

#### **5. Tables & Charts**  
✅ Insert a **table** with at least **3 columns and 5 rows**.  
✅ Apply table formatting (borders, shading, and bold headers).  
✅ Insert a **chart** using Word’s built-in chart feature and label it appropriately.  

#### **6. Images & Captions**  
✅ Insert **at least one image** related to the report’s topic.  
✅ Add a **caption** to the image.  
✅ Use **text wrapping** to adjust image placement.  

#### **7. Bullets & Numbering**  
✅ Include at least **one bulleted list** and **one numbered list**.  

#### **8. Hyperlinks & References**  
✅ Insert a **hyperlink** to an external website or related document.  
✅ Create a **bibliography** using the built-in reference manager.  
✅ Insert at least **two citations** using **APA or MLA** format.  

#### **9. Headers & Footers**  
✅ Add a **header** with your name and the report title.  
✅ Add a **footer** with page numbers and institution name.  

#### **10. Final Touch – Proofing & Review**  
✅ Use the **Spelling & Grammar Check** tool to correct errors.  
✅ Enable **Track Changes** and add at least one **comment** in the document.  
✅ Save the file as **.docx** and **PDF**.
